<tyro-ui-dashboard-layout>

Dashboard Layout

Layout complet avec sidebar collapsible, navbar intégrée et gestion mobile. Reçoit les nav items, le logo, le projet et l'utilitaire en Input.

Inputs
Propriétés disponibles
Input Type Description
[project]stringNom du projet affiché dans la navbar et la sidebar
[utility]stringLabel utilitaire (ex : "Dashboard", "Hub")
[logo]stringURL du logo couleur (navbar)
[logoWhite]stringURL du logo blanc (sidebar mobile)
[navItems]ITyroUiDashNavItem[]Items de navigation (liens, groupes, catégories)
Interface ITyroUiDashNavItem
Structure des nav items
{
  label:     string
  icon:      string           // classe remix-icon
  iconImg?:  string           // URL image (remplace l'icône)
  link?:     string           // routerLink — absent si groupe/catégorie
  category?: boolean          // section collapsible (pas un lien)
  children?: {
    label:    string
    icon:     string
    iconImg?: string
    link?:    string
    children?: { label, icon, iconImg?, link }[]
    open?:    boolean
  }[]
  open?:     boolean
}

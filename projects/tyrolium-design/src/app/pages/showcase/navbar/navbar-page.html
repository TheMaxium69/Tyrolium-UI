Inputs

PropriétéTypeDéfautDescription
[project] string '' Nom du projet affiché dans la navbar (ex : "Tyrolium", "Useritium")
[logo] string '' URL du logo affiché à gauche — si vide, aucun logo
[subtitle] string '' Label utilitaire affiché sous le projet en mode sidebar (ex : "Dashboard")
[pages] ITyroUiNavbarPages[] [] Liens de navigation affichés dans la barre (voir interface ci-dessous)
[placeholder] boolean true Affiche un bloc vide sous la navbar pour compenser son position: fixed
[sidebar] boolean false Mode dashboard — passe la navbar en position: relative et affiche un burger qui émet sidebarBurgerClick
[currentUser] any[] [] Déprécié Utiliser TyroUiAuthService à la place
Outputs
@Output()
ÉvénementPayloadDescription
(sidebarBurgerClick) void Émis quand le burger est cliqué en mode [sidebar]="true" — utilisé par tyro-ui-dashboard-layout pour ouvrir la sidebar mobile
(loginClick) void Émis après l'ouverture de la modale login (pour usage externe)
(registerClick) void Émis après l'ouverture de la modale inscription
(logoutClick) void Émis après la déconnexion via TyroUiAuthService.logout()

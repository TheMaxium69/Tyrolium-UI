<tyro-ui-auth-modal>

Auth Modal

Modal de connexion et d'inscription. Entièrement piloté par TyroUiAuthService — aucun @Input(). Il suffit de placer le composant une fois dans le template racine.

Démo
Déclencher la modale via TyroUiAuthService
TyroUiAuthService — API publique
Méthodes et signals
MembreTypeDescription
openModal(mode)'login' | 'register'Ouvre la modale dans le mode choisi
closeModal()voidFerme la modale (aussi déclenché par clic sur l'overlay ou Escape)
login(login, password)Promise<void>Soumet le formulaire de connexion à l'API Useritium
logout()voidDéconnecte l'utilisateur et efface la session
user()Signal<ITyroUiUser | null>Signal de l'utilisateur connecté — null si non connecté
modalOpen()Signal<boolean>Signal d'état d'ouverture de la modale
modalMode()Signal<'login' | 'register'>Signal du mode actuel de la modale
error()Signal<string>Message d'erreur de la dernière tentative de connexion
Usage
Intégration minimale
// app.html — placer une seule fois
<tyro-ui-auth-modal></tyro-ui-auth-modal>

// n'importe quel composant
readonly auth = inject(TyroUiAuthService);

// ouvrir
this.auth.openModal('login');
this.auth.openModal('register');

// lire l'utilisateur
const user = this.auth.user(); // ITyroUiUser | null

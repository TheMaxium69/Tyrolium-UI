<tyro-ui-dashboard-layout>

Dashboard Layout

Layout complet avec sidebar collapsible, navbar intégrée et gestion mobile. Encapsule tyro-ui-navbar et projette le contenu des pages via <ng-content>.

Inputs
@Input()
PropriétéTypeDéfautDescription
[project]string''Nom du projet — affiché dans la navbar et la sidebar
[utility]string''Label utilitaire (ex : "Dashboard", "Hub") — texte secondaire dans sidebar et navbar mobile
[logo]string''URL du logo couleur (barre de titre navbar)
[logoWhite]string''URL du logo blanc (sidebar mobile)
[navItems]ITyroUiDashNavItem[][]Arborescence de navigation (voir interfaces ci-dessous)
Interface — ITyroUiDashNavItem
Item de navigation (niveau 1)
ChampTypeDescription
labelstringTexte affiché dans la sidebar
iconstringClasse remix-icon (utilisée si iconImg absent)
iconImg?stringURL d'image remplaçant l'icône (logos projets, etc.)
link?stringRoute Angular — absent si groupe ou catégorie
category?booleanTransforme l'item en section collapsible (pas un lien, style header réduit)
children?ITyroUiDashNavChild[]Sous-items (niveau 2)
open?booleanÉtat ouvert/fermé du groupe ou de la catégorie
ITyroUiDashNavChild (niveau 2)
ChampTypeDescription
labelstringTexte affiché
iconstringClasse remix-icon
iconImg?stringURL image à la place de l'icône
link?stringRoute — absent si sous-groupe
children?ITyroUiDashNavSubItem[]Sous-sous-items (niveau 3)
open?booleanÉtat du sous-groupe
ITyroUiDashNavSubItem (niveau 3)
ChampTypeDescription
labelstringTexte affiché
iconstringClasse remix-icon
iconImg?stringURL image à la place de l'icône
linkstringRoute Angular (obligatoire au niveau 3)
Comportement sidebar
États et transitions
ÉtatDéclencheurEffet
Expanded (desktop)Par défautSidebar 240px, labels visibles
Collapsed (desktop)Bouton chevron haut de sidebarSidebar 60px, icônes seules + tooltip au survol
Open (mobile)Burger navbarSidebar en overlay (z-index: 1002) par-dessus le contenu
Close (mobile)Clic overlay / lien / bouton fermer / EscapeSidebar repasse en translateX(-100%)
Usage
app.html
<tyro-ui-dashboard-layout
  [project]="'Useritium'"
  [utility]="'Dashboard'"
  [logo]="'assets/tyrolium-ui/projects/Useritium.png'"
  [logoWhite]="'assets/tyrolium-ui/projects/Useritium-White.png'"
  [navItems]="navItems">
  <router-outlet />
</tyro-ui-dashboard-layout>
